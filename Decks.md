Decks are basically just an array of card print IDs, and they are stored as a basic Json dictionary with two keys: Home base which is a single string print ID, and the main board which is an array of print IDs.
# Features

- Shuffle
- Add (Use the modular card list I mention in [[Deck List Edit-Save-Load]])
	- To top
	- To bottom
	- To position from top
	- To position from bottom
	- And shuffle
- Search
